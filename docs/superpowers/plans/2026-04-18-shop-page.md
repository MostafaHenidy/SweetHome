# Shop Page Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle `/shop` to closely match the provided showroom screenshot while preserving the current Livewire filters, sorting, pagination, and product links.

**Architecture:** Keep all shopping logic in the existing `ShopPage` Livewire component and move the visual work into Blade views. Build the new page as a full-width hero plus a two-column catalog shell, then tune the reusable product card so the grid matches the reference without changing data flow or routes.

**Tech Stack:** Laravel, Livewire, Blade, Tailwind CSS, PHPUnit

---

## File map

- `resources/views/livewire/shop-page.blade.php` — replace the current breadcrumb-first layout with the showroom hero, left filter rail, sort row, empty state, and responsive catalog grid.
- `resources/views/components/product-card.blade.php` — restyle the reusable card surface, image crop, title/price hierarchy, and gold CTA treatment while keeping the product detail link.
- `resources/views/layouts/app-shop.blade.php` — touch only if the fixed nav / main padding needs a small adjustment to let the hero sit correctly under the header.
- `tests/Feature/ShopPageUiTest.php` — add coverage for the page shell and route behavior so the redesign does not break rendering.

## Gaps to watch for during implementation

- If the fixed nav clashes with the hero, adjust only `resources/views/layouts/app-shop.blade.php` padding.
- If product images crop awkwardly, tune the aspect ratio in `resources/views/components/product-card.blade.php` rather than changing the media pipeline.
- If the page still feels too light, push the background and card surfaces darker before widening the scope.
